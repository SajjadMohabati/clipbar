کلیپ‌بار هر چی روی لینوکس کپی می‌کنی رو نگه می‌داره: متن، لینک، رنگ، عکس و فایل. `Ctrl+Shift+V` رو بزن، آیتم رو انتخاب کن و همون‌جایی که داشتی تایپ می‌کردی پیست می‌شه. تازه از **چیزی که تایپ می‌کنی** هم یه کپی نگه می‌داره، که اگه فرم پرید یا پیام ارسال نشد، متنت از دست نره.

<a id="drafts"></a>

## Drafts: برگردوندن متنی که تایپ کردی و پرید

یه پیام بلند می‌نویسی، ارسال رو می‌زنی و همه‌ش می‌پره. صفحه دوباره لود شده، نشست منقضی شده، برنامه بسته شده یا اشتباهی تب رو بستی.

**قابلیت Drafts کلیپ‌بار هر چی تایپ می‌کنی رو همون موقع ذخیره می‌کنه**، توی هر برنامه‌ای که از دسترس‌پذیری لینوکس پشتیبانی کنه، حتی اگه کپی‌اش نکرده باشی. کلیپ‌بار رو باز کن، برو تب **Drafts** و دوباره پیستش کن.

| چه اتفاقی افتاد | کلیپ‌بار چیکار می‌کنه |
| --- | --- |
| فرم سایت خالی شد یا صفحه دوباره لود شد | متنت توی Drafts هست |
| «پیام ارسال نشد» و کادر پیام خالی شده | متنت توی Drafts هست |
| تب رو بستی یا برنامه بسته شد | متنت توی Drafts هست |
| همه‌ی متن رو انتخاب کردی و اشتباهی روش نوشتی | نسخه‌ی قبلی توی Drafts هست |

**چطوری کار می‌کنه**

1. یه بار از **Settings → Drafts** روشنش کن.
2. هر جا خواستی تایپ کن: مرورگر، پیام‌رسان، ایمیل، فرم‌ها، یادداشت‌ها.
3. کلیپ‌بار برای **هر پیام یه پیش‌نویس** نگه می‌داره. تا وقتی تایپ می‌کنی به‌روز می‌شه و وقتی فیلد خالی شد (ارسال یا پاک شد)، متن کامل توی Drafts می‌مونه.
4. چیزی از دست دادی؟ `Ctrl+Shift+V` رو بزن، برو **Drafts** و `Enter` بزن.

**امن و خصوصی**

- **کی‌لاگر نیست.** کلیپ‌بار هیچ‌وقت به کیبورد گوش نمی‌ده. فقط ثانیه‌ای یه بار متن فیلد فعال رو از سرویس دسترس‌پذیری لینوکس (AT-SPI) می‌پرسه.
- فیلدهای رمز و جست‌وجو رو **هیچ‌وقت نمی‌خونه**، و از ترمینال‌ها، برنامه‌های مدیریت رمز و هر برنامه‌ای که نتونه بشناسه رد می‌شه. روی X11 و Wayland دقیقاً همین‌طوره.
- شماره کارت و کلیدهای API ذخیره نمی‌شن، پیش‌نویس‌ها خودشون منقضی می‌شن و هیچی از کامپیوترت بیرون نمیره.
- **پیش‌فرض خاموشه.** حداقل طول (۳۰ کاراکتر)، مدت نگهداری (۱۲ ساعت) و تعداد (۱۰ تا) دست خودته.
- متن فارسی و راست‌به‌چپ کامل پشتیبانی می‌شه.

<a id="features"></a>

## قابلیت‌ها

### تاریخچه‌ی کلیپ‌بورد
- **متن، لینک، رنگ، عکس و فایل** رو با زمان کپی نگه می‌داره.
- **فیلترها:** همه · پین‌شده · متن · لینک · عکس · فایل (`Tab` و `Shift+Tab`).
- **جست‌وجوی فوری** توی متن‌ها، عنوان‌ها و متن داخل عکس‌ها.
- **پین کردن** آیتم‌های مهم. اگه یه چیز تکراری کپی کنی، آیتم تکراری درست نمی‌شه و همون قبلی میاد بالا.
- **پاک‌سازی خودکار** بر اساس سن (۱ تا ۳۶۵ روز) و تعداد (۵۰ تا ۲۰۰۰ آیتم). آیتم‌های پین‌شده می‌تونن همیشه بمونن.

### آیتم‌های ذخیره‌شده و قفل رمزنگاری‌شده
- یه لیست جدا به اسم **Saved** برای چیزهایی که مدام پیست می‌کنی: شماره کارت، آدرس، امضای ایمیل.
- **برای هر آیتم ذخیره‌شده عنوان بذار**، چه متن باشه چه عکس. عنوان‌ها توی جست‌وجو پیدا می‌شن.
- **قفلش کن:** مقدارش با **AES-256-GCM** رمزنگاری می‌شه، با کلیدی که با **scrypt** از رمز کلیپ‌بار ساخته می‌شه. خود رمز هیچ‌جا ذخیره نمی‌شه، پس رمز اشتباه یا خالی اصلاً نمی‌تونه بازش کنه.
- بعد از باز کردن قفل، ۳۰ ثانیه وقت داری؛ بعدش کلید از حافظه پاک می‌شه.

### اسکرین‌شات و OCR
- اسکرین‌شات‌های جدید توی `~/Pictures/Screenshots` (یا پوشه‌ی Pictures) **خودکار به تاریخچه اضافه و کپی می‌شن**.
- **تشخیص متن داخل عکس** با Tesseract و روی خود سیستم. متن عکس‌ها قابل جست‌وجوئه.

### پیست و ویرایش
- **پیست مستقیم:** `Enter` توی برنامه‌ای که توش بودی پیست می‌کنه، `Alt+Enter` فقط کپی می‌کنه.
- **`Ctrl+1` تا `Ctrl+9`:** نُه آیتم اول رو فوری پیست می‌کنن.
- **ویرایشگر کامل** با تعداد کاراکتر، کلمه و خط، کد رنگ (HEX، RGB و HSL) و متن داخل عکس.
- **تبدیل متن با یه کلیک:** حروف بزرگ و کوچیک، Capitalize، حذف فاصله‌ها و خط‌های خالی، مرتب‌سازی، حذف تکراری‌ها، یکی کردن خط‌ها، فرمت یا فشرده کردن JSON، Base64 و URL encode/decode.

### حریم خصوصی
- **کلیدهای خصوصی، توکن‌های API** (GitHub، OpenAI، Stripe، AWS، Slack، Google و…) و **شماره کارت‌ها** (با الگوریتم Luhn) ذخیره نمی‌شن.
- **توقف موقت ضبط** از منوی آیکون کنار ساعت.
- بدون حساب کاربری، بدون فضای ابری، بدون آمارگیری و بدون هیچ درخواست اینترنتی.

<a id="install"></a>

## نصب

### اوبونتو و دبیان (پیشنهادی)

فایل **`clipbar_1.0.1_all.deb`** رو از [صفحه‌ی آخرین نسخه‌ی لینوکس](https://github.com/SajjadMohabati/clipbar/releases/tag/linux-v1.0.1) دانلود کن و نصبش کن:

<div dir="ltr">

```bash
sudo apt install ./clipbar_1.0.1_all.deb
```

</div>

برای Drafts این بسته‌ها هم لازمه:

<div dir="ltr">

```bash
sudo apt install python3-gi gir1.2-atspi-2.0 at-spi2-core
```

</div>

بعد **ClipBar** رو از منوی برنامه‌ها باز کن (یا `clipbar` رو اجرا کن) و `Ctrl+Shift+V` رو بزن. برای اجرای خودکار با روشن شدن سیستم، از Settings → General گزینه‌ی **Launch at login** رو روشن کن.

### فدورا

<div dir="ltr">

```bash
sudo dnf install python3-pyqt6 python3-cryptography python3-gobject at-spi2-core xdotool tesseract
git clone https://github.com/SajjadMohabati/clipbar.git
cd clipbar/clipbar-linux && ./build.sh install
```

</div>

### آرچ لینوکس و مانجارو

<div dir="ltr">

```bash
sudo pacman -S python-pyqt6 python-cryptography python-gobject at-spi2-core xdotool tesseract tesseract-data-eng
git clone https://github.com/SajjadMohabati/clipbar.git
cd clipbar/clipbar-linux && ./build.sh install
```

</div>

دستور `./build.sh install` کلیپ‌بار رو با یه آیکون توی منو، داخل `~/.local` نصب می‌کنه و از بسته‌های Python خود سیستم استفاده می‌کنه. `./build.sh uninstall` پاکش می‌کنه. برای امتحان بدون نصب، توی پوشه‌ی `clipbar-linux` دستور `python3 -m clipbar.main` رو بزن.

| بسته | برای |
| --- | --- |
| `python3-pyqt6`، `python3-pyqt6.qtsvg` | خود برنامه (لازم) |
| `python3-cryptography` | آیتم‌های قفل‌دار (لازم) |
| `python3-gi`، `gir1.2-atspi-2.0`، `at-spi2-core` | Drafts |
| `xdotool` (X11)، `wtype` یا `ydotool` (Wayland) | پیست مستقیم |
| `tesseract-ocr` | متن داخل عکس |
| `python3-pynput` | میانبر سراسری روی X11 |

### امتحان با Docker

روی هر کامپیوتری که Docker داره، حتی مک، می‌تونی نسخه‌ی لینوکس رو توی مرورگر ببینی:

<div dir="ltr">

```bash
cd clipbar-linux && ./run-docker.sh
```

</div>

بعد آدرس <http://localhost:6080/vnc.html?autoconnect=true&resize=scale> رو باز کن.

<a id="wayland"></a>

## Wayland

کلیپ‌بار روی GNOME و KDE با Wayland کار می‌کنه:

- **تاریخچه‌ی کلیپ‌بورد:** توی Wayland فقط پنجره‌ی فعال می‌تونه کلیپ‌بورد رو بخونه، برای همین کلیپ‌بار خودکار از طریق XWayland کلیپ‌بورد رو دنبال می‌کنه، که بین همه‌ی برنامه‌ها مشترکه.
- **میانبر:** Wayland اجازه نمی‌ده برنامه‌ها کلید سراسری بگیرن. از تنظیمات کیبورد دسکتاپت یه میانبر بساز (GNOME: *Settings → Keyboard → Custom Shortcuts*، KDE: *System Settings → Shortcuts*) با دستور `clipbar --toggle` و کلیدهای `Ctrl+Shift+V`.
- **پیست مستقیم:** `wtype` (برای Sway و Hyprland) یا `ydotool` (برای GNOME و KDE) رو نصب کن. بدون این‌ها، کلیپ‌بار آیتم رو کپی می‌کنه و خودت `Ctrl+V` می‌زنی.
- **Drafts:** دقیقاً مثل X11، از طریق AT-SPI کار می‌کنه.

<a id="shortcuts"></a>

## میانبرهای کیبورد

| کلید | کار |
| --- | --- |
| `Ctrl+Shift+V` | باز کردن کلیپ‌بار (از تنظیمات قابل تغییره) |
| `↑` `↓` | جابه‌جایی بین آیتم‌ها |
| `Enter` | پیست آیتم انتخاب‌شده |
| `Alt+Enter` | فقط کپی، بدون پیست |
| `Ctrl+1` تا `Ctrl+9` | پیست آیتم ۱ تا ۹ |
| `Tab` / `Shift+Tab` | فیلتر بعدی / قبلی |
| `Ctrl+[` / `Ctrl+]` | تب قبلی / بعدی (تاریخچه، پیش‌نویس‌ها، ذخیره‌شده‌ها) |
| `Ctrl+S` | انتقال به ذخیره‌شده‌ها |
| `Ctrl+P` | پین کردن یا برداشتن پین |
| `Ctrl+E` | دیدن و ویرایش |
| `Ctrl+Backspace` | حذف |
| `Ctrl+,` | تنظیمات |
| `Esc` | پاک کردن جست‌وجو، بعد بستن پنل |

از ترمینال: `clipbar --toggle` پنل رو باز و بسته می‌کنه و `clipbar --settings` تنظیمات رو باز می‌کنه.

<a id="faq"></a>

## سؤال‌های رایج

<details>
<summary><b>بهترین کلیپ‌بورد منیجر برای اوبونتو چیه؟</b></summary>

کلیپ‌بار یه کلیپ‌بورد منیجر رایگان و متن‌باز برای اوبونتوئه، با تاریخچه، جست‌وجو، آیتم‌های پین‌شده و ذخیره‌شده، قفل رمزنگاری‌شده، اسکرین‌شات، OCR و Drafts که متن تایپ‌شده‌ی گم‌شده رو برمی‌گردونه. فایل `.deb` رو از [صفحه‌ی نسخه](https://github.com/SajjadMohabati/clipbar/releases/tag/linux-v1.0.1) نصب کن.
</details>

<details>
<summary><b>چطوری تاریخچه‌ی کلیپ‌بورد رو توی لینوکس ببینم؟</b></summary>

کلیپ‌بار رو نصب کن و `Ctrl+Shift+V` رو بزن. هر چی از وقتی کلیپ‌بار اجرا شده کپی کردی، از جدید به قدیم نشون داده می‌شه. می‌تونی جست‌وجو یا فیلترش کنی و هر آیتم رو با `Enter` پیست کنی.
</details>

<details>
<summary><b>چطوری متنی که توی لینوکس تایپ کردم و پرید رو برگردونم؟</b></summary>

قابلیت **Drafts** رو از تنظیمات روشن کن. از اون به بعد، کلیپ‌بار از متن‌های بلندی که تایپ می‌کنی یه کپی نگه می‌داره. اگه فرم پرید یا پیام ارسال نشد، برو تب **Drafts** و دوباره پیستش کن. متنی که قبل از روشن کردن Drafts تایپ شده قابل برگشت نیست.
</details>

<details>
<summary><b>قابلیت Drafts کی‌لاگره؟</b></summary>

نه. کلیپ‌بار هیچ‌وقت کیبورد رو نمی‌خونه. ثانیه‌ای یه بار متن فیلد فعال رو از سرویس دسترس‌پذیری می‌پرسه، فیلدهای رمز و جست‌وجو رو نمی‌خونه، و از ترمینال‌ها، برنامه‌های مدیریت رمز و برنامه‌های ناشناخته رد می‌شه. تا خودت روشنش نکنی خاموشه و همه‌چیز روی کامپیوتر خودت می‌مونه.
</details>

<details>
<summary><b>آیتم‌های قفل‌دار چقدر امنن؟</b></summary>

با AES-256-GCM رمزنگاری می‌شن. کلید با scrypt از رمز کلیپ‌بار ساخته می‌شه و هیچ‌وقت روی دیسک نوشته نمی‌شه، پس فایل رمزنگاری‌شده بدون رمز باز نمی‌شه. اگه رمز رو فراموش کنی، آیتم‌های قفل‌دار قابل برگشت نیستن.
</details>

<details>
<summary><b>کلیپ‌بار روی Wayland کار می‌کنه؟</b></summary>

بله، روی GNOME و KDE. برای میانبر سراسری و پیست مستقیم، بخش [Wayland](#wayland) رو ببین.
</details>

<details>
<summary><b>کلیپ‌بار لینوکس رایگانه؟</b></summary>

بله. کاملاً رایگان و متن‌بازه، با لایسنس MIT، بدون حساب کاربری، اشتراک یا ردیابی.
</details>

## داده‌های تو

کلیپ‌بار از پوشه‌های استاندارد XDG استفاده می‌کنه:

- `~/.local/share/clipbar/history.json`: تاریخچه‌ی کلیپ‌بورد
- `~/.local/share/clipbar/saved.json`: آیتم‌های ذخیره‌شده (مقدار آیتم‌های قفل‌دار فقط رمزنگاری‌شده توی `vault.enc`ه)
- `~/.local/share/clipbar/drafts.json`: پیش‌نویس‌ها، اگه Drafts روشن باشه
- `~/.local/share/clipbar/images/`: عکس‌های کپی‌شده، هر کدوم یه بار به‌شکل PNG
- `~/.config/clipbar/settings.json`: تنظیمات

برای شروع از صفر، کلیپ‌بار رو ببند و این پوشه‌ها رو پاک کن.
