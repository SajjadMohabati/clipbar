## پیش‌نویس‌ها (Drafts): دیگر هرگز متنی که تایپ کردید را از دست ندهید

متن طولانی می‌نویسید، روی ارسال می‌زنید و همه‌چیز ناپدید می‌شود: فرم ریست شده، نشست منقضی شده، مرورگر یا برنامه بسته شده، یا اشتباهی دستتان خورده و متن پاک شده است. هیچ‌کس دوست ندارد دوباره از اول تایپ کند.

**بخش Drafts کلیپ‌بار متنی که تایپ می‌کنید را همان لحظه ذخیره می‌کند**، در هر برنامه‌ای، حتی اگر هرگز آن را کپی نکرده باشید! هر زمان متنتان ناپدید شد، کافیست کلیپ‌بار را باز کرده، به تب **Drafts** بروید و آن را بازگردانید.

| چه اتفاقی افتاد؟ | کلیپ‌بار چه می‌کند؟ |
| --- | --- |
| فرم ریست شد یا صفحه رفرش شد | متن کامل در Drafts ذخیره شده است |
| پیام ارسال نشد و جعبه متن خالی شد | متن در Drafts موجود است |
| تب مرورگر یا برنامه ناگهان بسته شد | متن در Drafts باقی مانده است |
| متن را انتخاب کرده و اشتباهی پاک کردید | نسخه قبلی در Drafts در دسترس است |

**نحوه کارکرد**

1. یک بار آن را از مسیر **Settings → Drafts** فعال کنید.
2. در هر برنامه‌ای تایپ کنید: پیام‌رسان‌ها، ایمیل، مرورگر، یادداشت‌ها.
3. کلیپ‌بار برای هر پیام **یک پیش‌نویس** نگه می‌دارد. همزمان با تایپ شما به‌روزرسانی می‌شود و زمانی که فیلد خالی شد (ارسال شد یا پاک شد)، متن نهایی در بخش Drafts محفوظ می‌ماند.
4. با زدن میانبر `Ctrl+Shift+V`، انتخاب تب **Drafts** و زدن `Enter`، متن دقیقاً در همان محل تایپ بازگردانده می‌شود.

**امن و کاملاً خصوصی**

- **این یک کی‌لاگر نیست.** کلیپ‌بار هرگز به ورودی‌های کیبورد گوش نمی‌دهد. ثانیه‌ای یک‌بار از طریق Accessibility لینوکس (AT-SPI2) متن کادر فوکوس‌شده را دریافت می‌کند.
- **فیلدهای رمز عبور هرگز خوانده نمی‌شوند.** ترمینال‌ها، برنامه‌های مدیریت رمز و کادرهای حساس به‌طور خودکار رد می‌شوند.
- در حالت پیش‌فرض غیرفعال است و همه داده‌ها روی سیستم شما می‌ماند؛ هیچ چیزی به اینترنت ارسال نمی‌شود.
- پشتیبانی کامل و بی‌نقص از راست‌به‌چپ (فارسی، عربی، عبری).

## ویژگی‌ها

### تاریخچه کلیپ‌بورد
- به خاطر سپردن **متن‌ها، لینک‌ها، کدهای رنگی (#HEX)، تصاویر و فایل‌ها**.
- **فیلترها**: All · Pinned · Text · Links · Images · Files (با کلید `Tab`).
- **جستجوی آنی** در متن، عنوان‌ها و حتی متن داخل تصاویر!
- سنجاق کردن (Pin) موارد مهم به بالای لیست.
- پاکسازی خودکار بر اساس زمان (۱ تا ۳۶۵ روز) و تعداد (۵۰ تا ۲,۰۰۰ مورد).

### موارد ذخیره‌شده و امنیت (Saved & Vault)
- لیست جداگانه برای اطلاعات پرکاربرد: شماره کارت بانکی، کد ملی، آدرس، امضای ایمیل.
- افزودن با دکمه **+** یا زدن `Ctrl+S` روی هر مورد از تاریخچه.
- **قفل کردن با رمز عبور**: بار اول یک رمز برای ClipBar انتخاب می‌کنید. مقدار با AES-256-GCM و کلیدی که از همین رمز ساخته می‌شود رمزنگاری شده و به‌صورت `••••••••` نمایش داده می‌شود؛ قبل از هر بار کپی، پیست، ویرایش یا حذف، رمز پرسیده می‌شود (تا ۳۰ ثانیه به خاطر می‌ماند). اگر رمز را فراموش کنید، اقلام قفل‌شده قابل بازیابی نیستند.

### تصاویر و اسکرین‌شات‌ها
- ذخیره خودکار اسکرین‌شات‌ها از پوشه `~/Pictures/Screenshots` به تاریخچه.
- **تشخیص متن داخل تصویر (OCR)** با Tesseract: متن عکس‌ها و اسکرین‌شات‌ها قابل جستجو و کپی می‌شود.

### ویرایشگر و تبدیل متن (Editor & Transforms)
- مشاهده و ویرایش کامل به همراه پنل مشخصات (تعداد کاراکتر، کلمه، خط، کد رنگ و ابعاد تصویر).
- **۱۳ تبدیل متنی**: بزرگ/کوچک کردن حروف، حذف خطوط خالی، مرتب‌سازی الفبایی، حذف خطوط تکراری، ادغام خطوط، فرمت و فشرده‌سازی JSON، کدگذاری Base64 و URL Encode.

## نصب

### اوبونتو و دبیان (Ubuntu & Debian)

```bash
# ۱. نصب پیش‌نیازهای سیستم
sudo apt update
sudo apt install -y python3 python3-pyqt6 python3-pyqt6.qtsvg python3-cryptography xdotool tesseract-ocr \
  python3-gi gir1.2-atspi-2.0 at-spi2-core

# ۲. دریافت و نصب کلیپ‌بار
git clone https://github.com/SajjadMohabati/clipbar-mac.git
cd clipbar-mac/clipbar-linux
./build.sh install
```

یا با استفاده از بسته دبیان (`.deb`):
```bash
cd clipbar-linux
./build.sh deb
sudo dpkg -i dist/clipbar_*.deb || sudo apt install -f
```

---

### فدورا و ردهت (Fedora / RHEL)

```bash
sudo dnf install -y python3 python3-pyqt6 xdotool tesseract
cd clipbar-linux
./build.sh install
```

---

### آرچ لینوکس (Arch Linux)

```bash
sudo pacman -S python python-pyqt6 xdotool tesseract
cd clipbar-linux
./build.sh install
```

## میانبرهای صفحه‌کلید

| کلید | عملکرد |
| --- | --- |
| `Ctrl+Shift+V` | باز کردن پنل کلیپ‌بار (قابل تغییر در تنظیمات) |
| `↑` `↓` | جابه‌جایی بین گزینه‌ها |
| `Enter` | پیست مستقیم در برنامه فعال |
| `Alt+Enter` | کپی بدون پیست کردن |
| `Ctrl+1` تا `Ctrl+9` | پیست سریع موارد ۱ تا ۹ |
| `Tab` / `Shift+Tab` | جابه‌جایی بین فیلترها |
| `Ctrl+[` / `Ctrl+]` | جابه‌جایی بین تب‌ها (History / Drafts / Saved) |
| `Ctrl+S` | انتقال به Saved |
| `Ctrl+P` | سنجاق کردن / خارج کردن از سنجاق |
| `Ctrl+E` | نمایش و ویرایش در پنجره ویرایشگر |
| `Ctrl+Backspace` | حذف مورد انتخاب شده |
| `Ctrl+,` | باز کردن تنظیمات |
| `Esc` | پاک کردن جستجو، سپس بستن پنل |

## داده‌های شما

تمام داده‌ها طبق استاندارد XDG لینوکس ذخیره می‌شوند:
- `~/.local/share/clipbar/history.json`: تاریخچه
- `~/.local/share/clipbar/saved.json`: اقلام ذخیره‌شده
- `~/.local/share/clipbar/drafts.json`: پیش‌نویس‌ها
- `~/.local/share/clipbar/images/`: تصاویر کپی‌شده
- `~/.config/clipbar/settings.json`: تنظیمات
